# IBM Plex Sans

`ibm-plex-sans-latin.woff2` is the IBM Plex Sans variable font, with weights
400–700 and the Latin subset, including Brazilian Portuguese characters.
Next.js serves and preloads this local file through `next/font/local`.

Source: [Google Fonts WOFF2](https://fonts.gstatic.com/s/ibmplexsans/v23/zYXzKVElMYYaJe8bpLHnCwDKr932-G7dytD-Dmu1syxeKYY.woff2).
The font uses the SIL Open Font License 1.1 in `OFL.txt`.

# IBM Plex Mono

`ibm-plex-mono-latin-400.woff2`, `-500` and `-600` are static IBM Plex Mono
weights with the Latin subset. They set tickers, formulas, and keyboard hints
only; financial values keep IBM Plex Sans with tabular numerals.

Source: Google Fonts WOFF2 (`fonts.gstatic.com/s/ibmplexmono/v20`). IBM Plex
Mono uses the same SIL Open Font License 1.1 in `OFL.txt`.

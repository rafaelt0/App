# IBM Plex Sans

`ibm-plex-sans-latin.woff2` is the IBM Plex Sans variable font, with weights
400–700 and the Latin subset, including Brazilian Portuguese characters.
Next.js serves and preloads this local file through `next/font/local`.

Source: [Google Fonts WOFF2](https://fonts.gstatic.com/s/ibmplexsans/v23/zYXzKVElMYYaJe8bpLHnCwDKr932-G7dytD-Dmu1syxeKYY.woff2).

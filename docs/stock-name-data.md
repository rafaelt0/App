# Local B3 stock names

`acoes-listadas-b3.csv` retains its original 335 ticker/sector rows in order. `Empresa` is the exchange trading name and `RazaoSocial` the issuer's legal name when verified. Snapshot collected from [B3's listed securities pages](https://bvmf.bmfbovespa.com.br/cias-listadas/Titulos-Negociaveis/ResumoTitulosNegociaveis.aspx?or=bus&tip=I&cb=A&idioma=pt-BR), all A–Z letter pages, matching the `cb=` issuer code to the first four characters of each ticker (271 of 277 roots; 328 of 335 ticker rows).

Exceptions absent from the letter pages: [BRBI B3 detail](https://bvmf.bmfbovespa.com.br/cias-listadas/Titulos-Negociaveis/DetalheTitulosNegociaveis.aspx?or=res&cb=BRBI&tip=I&idioma=pt-BR) confirms BRBI11 and both names; [Oi investor page](https://ri.oi.com.br/informacoes-ao-investidor/oibr3/) confirms OIBR3/OIBR4; [Yahoo historical chart](https://query1.finance.yahoo.com/v8/finance/chart/FICT3.SA?range=5d&interval=1d) confirms FICT3 / Fictor Alimentos S.A.; [Yahoo chart](https://query1.finance.yahoo.com/v8/finance/chart/SHOW3.SA?range=5d&interval=1d) confirms SHOW3 / T4F Entretenimento S.A. [Investidor10 NGRD3](https://www.investidor10.com.br/acoes/ngrd3/) identifies NEOGRID PARTICIPAÇÕES S.A.; [Investidor10 TRAD3](https://www.investidor10.com.br/acoes/trad3/) identifies Economatica, but gives no verified legal name, so `RazaoSocial` is blank for TRAD3. NGRD3 and TRAD3 no longer return current Yahoo charts and none of FICT/NGRD/TRAD appears in the current B3 letter listing: those three links have **no current B3/company-source confirmation**. Names for these exceptions are attributed to the alternative sources above, not inferred from ticker spelling. Coverage: 335/335 searchable trading names, 334/335 legal names (TRAD3 unresolved). No live name lookups occur in the app.
